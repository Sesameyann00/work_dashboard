# V1 试运行与上线验收

## 数据导入

- [ ] 真实脱敏样表字段映射已由会员中心主管确认
- [ ] 重复手机号、缺失姓名、非法等级和非法日期均进入错误行
- [ ] 同一文件重复导入不会增加重复会员、治疗或任务
- [ ] 历史治疗全部进入时间轴，只有最近周期的合规节点成为待办

## 角色权限

- [ ] 管理层可以查看全部数据但不能修改
- [ ] 会员中心主管可以维护会员、到诊、治疗和 D1–D30
- [ ] 护士长只能查看并确认 D0
- [ ] 匿名、停用账号和直接访问无权限页面均被拒绝

## 核心流程

- [ ] 新增治疗生成一条到诊和 D0/D1/D3/D7/D15/D30 六条任务
- [ ] 重复提交不会生成重复数据
- [ ] 再次治疗只覆盖旧周期未完成任务，已完成历史保留
- [ ] 生日礼月初生成，25 日仅提醒未领取会员
- [ ] 有效期 90/30/7 天提醒正确，修改有效期不改变等级
